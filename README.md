# 暮らしのルール変更レター（MVP試作）

法律・行政制度・生活に関わる重要ルールの変更を、生活者向けに短く整理して届ける無料サービスの試作です。

## 0円開発方針
- 有料APIを前提にしない
- Cloudflare Workers / D1 の無料枠内を目標にする
- AI APIはまだ接続しない
- メール配信は既存のBrevo無料枠の条件を確認してから接続する
- 補助金レターの本番DB・環境変数・配信処理とは分離する

## 現在の状態
- `GET /`: サービス説明とダミー記事の画面
- `GET /api/health`: ヘルスチェック
- `GET /api/updates`: ダミー記事JSON
- `schema.sql`: D1用の初期スキーマ
- `wrangler.toml`: Workers設定

**表示される記事はダミーです。実際の法改正情報ではなく、実データ収集・AI解説・メール配信は未実装です。**

## 次の実装順
1. ローカルで画面とAPIを確認
2. 新規D1データベースに `schema.sql` を適用
3. e-Gov法令APIのレスポンスを検証
4. 重複排除してD1に保存
5. AIなしで変更候補を一覧表示
6. 手動確認用の承認フロー
7. メール配信を接続
8. 無料で継続利用できるAI実行方法が確認できたら解説生成を追加

## 情報源候補
- e-Gov法令API Version 2: https://laws.e-gov.go.jp/api/2/swagger-ui
- デジタル庁の新着情報: https://www.digital.go.jp/rss

取得できることと再配信できることは別です。情報源ごとの利用条件・再配信条件を確認します。

## ローカル起動
```bash
npm install --save-dev wrangler
npx wrangler dev
```

独自ドメインは購入せず、まずはWorkers URLで試します。法令の公布日と施行日を区別し、未確認情報は配信しないでください。
