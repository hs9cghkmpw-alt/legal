# ルール変更レター MVP

## 基本方針
個人・法人を分けず、立場に応じたカテゴリを初期提案する。実際の配信対象は利用者自身が選択したカテゴリで決める。

## 処理フロー
1. メール・立場・カテゴリを登録
2. 確認メールで購読を有効化
3. 公式情報源の候補を収集
4. 外部IDで重複排除してD1に保存
5. キーワードでカテゴリ候補を付与
6. 記事は pending で保存し、管理者が原文を確認
7. 承認済み記事をカテゴリ照合して週次配信
8. sent に配信履歴を保存

## 安全方針
- 利用条件確認前は sources.terms_checked=0 とし収集停止
- 外部AI APIは使わない
- 未承認記事は配信しない
- 管理APIは Authorization: Bearer トークンを要求
- 公布日と施行日を混同しない
