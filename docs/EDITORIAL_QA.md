# 編集・原文照合・承認基準（MVP）

## 目的と公開条件

このサービスは公式情報への導線と平易な説明を提供する編集サービスであり、行政機関の公式見解・法律相談・期限管理システムではない。収集処理が動いたことだけでは、改正を検出できた／内容が正しいとは判断しない。

**情報源の利用条件を確認し、実データを原文と照合し、承認記録を残すまで配信しない。** 本文に未確認の箇所が1つでもあれば承認不可。確認者が運営者本人だけの場合も、最初の数件は日を置いて再確認する。

## 記事1件ごとの必須記録

- 一意な記事IDとステータス（候補／確認中／差戻し／承認済み／訂正／配信停止）
- 情報源名、公式ページURL、API/RSSの取得日時、原文確認日時
- 法令名・法令番号または行政発表の正式タイトル
- 公布日・公表日、施行日・適用開始日（別々に記録。分からない場合は「原文で未確認」とし、推測しない）
- 改正前後の差分と、差分を確認した条文・公式資料の箇所
- 対象者、影響する場面、必要な対応、期限（期限が原文にない場合は「期限の記載を確認できず」）
- 経過措置・例外・対象外の条件
- 読みやすい要約、根拠となる公式原文へのリンク
- 編集者、確認者、承認日時、公開・配信日時
- 不確実性、未確認点、訂正履歴、配信停止理由（該当時）

## 原文照合チェックリスト

承認前にすべて確認する。

- [ ] 公式ドメインの一次資料を開き、URLが有効である
- [ ] 正式名称と法令番号／資料タイトルが一致する
- [ ] 公布・公表日と施行・適用日を混同していない
- [ ] 改正法令だけでなく、必要な政令・省令・告示・附則・経過措置を確認した
- [ ] 「誰が対象か」を原文の適用条件に沿って説明している
- [ ] 「何が変わるか」と「利用者が何をする必要があるか」を区別した
- [ ] 期限や金額・割合・対象人数などの数字を原文と再照合した
- [ ] 例外・経過措置・未確定事項を省略して誤解を招いていない
- [ ] 要約と解説が行政機関の公式見解であるかのように見えない
- [ ] 出典・原文リンク・編集主体・確認日が表示される
- [ ] 個別の法的・税務的判断を断定していない
- [ ] 別の確認者による再確認、または時間を置いた再確認を記録した

## メール用記事テンプレート

**件名：** [分野] [変更の要点]（[施行・適用日。原文確認済みの場合のみ]）

**何が変わる？**
原文に記載された変更点を2〜4文で説明する。推測や将来予測を事実として書かない。

**誰に関係する？**
対象者と、対象外または条件付きとなるケースを記載する。原文だけで対象範囲を確定できない場合は、確認できた範囲を明示する。

**何を確認・対応する？**
読者が取れる具体的な確認行動を記載する。法的義務や期限は公式資料で明記されている場合に限り断定する。

**日付**
- 公布・公表日：
- 施行・適用日：
- 経過措置・期限：

**出典**
- 公式資料名：
- 公式原文URL：
- 原文確認日：
- 編集・加工：ルール便（仮称）

**注意**
本メールは一般情報です。個別事情に応じた法的・税務的判断や期限管理の代わりにはなりません。

## 差戻し・訂正・配信停止

- 根拠URLが開けない、一次資料が見つからない、日付・対象範囲が一致しない場合は差戻し。
- 誤りの可能性が判明したら該当記事の配信を止め、影響範囲を確認する。すでに配信した場合は、訂正内容・訂正日時・対象配信を記録し、必要に応じて訂正メールを送る。
- 誤りの報告窓口、対応責任者、対応目標時間を公開前に決める。
- RSSタイトルだけ、検索結果の抜粋だけ、AIの説明だけを根拠に承認しない。
- 自動抽出候補はすべて「未確認」。AIを導入しても、AIの出力だけで承認・配信しない。

## 初期の品質ゲート

初期公開前に少なくとも5件の実際の候補を使い、原文との一致、誤検出、見落とし、施行日・経過措置の抽出を記録する。5件は品質保証の統計的根拠ではなく、実運用の問題を見つける最低限のスモークテストである。

1件でも重大な日付誤り、対象者誤り、根拠リンク切れがあれば配信開始を保留し、原因修正後に再試験する。検出対象が網羅的であることを主張しない。
