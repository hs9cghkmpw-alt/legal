- 2026-10-12再確認：e-Gov Developer利用規約（https://developer.e-gov.go.jp/contents/terms）は、同サイトの特記のないコンテンツにPDL1.0を適用し、出典と編集・加工主体の表示を求める。ただし、これは法令APIが返す全データの再利用条件を一括で確定するものではない。
- 法令API Version 2仕様（https://laws.e-gov.go.jp/api/2/swagger-ui/）は、取得可能な法令データ範囲を別ページで確認するよう案内し、一部JSONレスポンスを試行版としている。
